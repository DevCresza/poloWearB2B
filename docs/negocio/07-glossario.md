# 7. Glossário

Os termos abaixo são os usados nas telas do portal e nas conversas com lojas e fornecedores.

| Termo | Significado |
|---|---|
| Admin | Usuário da equipe Polo Wear com acesso total |
| Aguardando pagamento | Pedido entregue que ainda tem título a pagar |
| Arquivar | Tirar um produto ou cápsula de circulação sem apagar o histórico |
| Bloqueio | Impede cliente ou loja de fazer pedido novo; decidido pela administração |
| Boleto faturado | Boleto emitido pelo fornecedor depois da nota fiscal, em parcelas com prazo |
| Cadastro (papel) | Usuário que cadastra produtos e cápsulas, com preço |
| Cápsula | Kit de coleção de um fornecedor, com quantidades mínimas por produto, cor ou tamanho |
| Carteira | Lista de títulos a pagar e pagos de um cliente, loja ou fornecedor |
| Catálogo | Vitrine de produtos e cápsulas liberados para o tipo de cliente |
| Comprovante | Arquivo que a loja envia para provar o pagamento de um título |
| Conferência de cobrança | Comparação, nota a nota, entre o valor faturado e os títulos |
| Em análise | Título com comprovante enviado, aguardando aprovação |
| Em produção | Pedido aceito pelo fornecedor |
| Em transporte | Pedido enviado, com transportadora e rastreio |
| Emissão em lote | Pedidos de uma cápsula criados pela administração para várias lojas |
| Essencial | Selo de produto que toda loja deveria ter; não obriga a compra |
| Estoque baixo | Produto com controle de estoque no limite mínimo ou abaixo |
| Faturado | Pedido com todos os itens cobertos por nota fiscal |
| Faturamento | Registro de uma nota fiscal emitida para o pedido |
| Finalizado | Pedido recebido e pago |
| Fornecedor | Marca que vende pelo portal e atende os pedidos |
| Franqueado | Loja da rede de franquias; tem preço e mínimo próprios |
| Frete FOB | Frete pago pelo cliente; pode vir incluso no boleto |
| Grade | Conjunto fixo de tamanhos vendido junto; a quantidade é contada em grades |
| Loja | Unidade de um cliente, com endereço e CNPJ próprios; o pedido vai para uma loja |
| Mês de entrega | Mês em que cada item deve ser entregue |
| Mês de faturamento | Mês de emissão da nota fiscal |
| Multimarca | Loja independente que vende várias marcas; tem preço e mínimo próprios |
| NF | Nota fiscal eletrônica (PDF e XML) |
| Novo pedido | Pedido enviado, aguardando o fornecedor aceitar |
| Parcela | Título de boleto com número e vencimento, ligado a uma nota |
| Parcialmente faturado | Pedido com parte dos itens já faturada |
| Pedido mínimo | Valor mínimo por fornecedor para fechar o pedido, por tipo de cliente |
| Pré-venda | Produto vendido antes de existir, para produção futura |
| Pronta entrega | Produto em estoque; o pedido baixa o estoque na hora |
| Quebra | Item que não será entregue por problema de produção; reduz o valor do pedido |
| Replicar pedido | Enviar o mesmo carrinho para várias lojas do cliente |
| Revisão de itens | Ajuste dos itens de um pedido feito pela equipe ou pelo fornecedor |
| Sob encomenda | Produto produzido a partir do pedido, sem controle de estoque |
| Título | Valor a receber, com vencimento e situação |
| Título provisório | Título criado no fechamento do pedido, substituído pelas parcelas da nota |
| Vencido | Título pendente com vencimento antes de hoje |
| Vendedor | Representante que compra em nome de um cliente |
